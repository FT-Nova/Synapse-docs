# Memory System

SYNAPSE uses a three-tier agent memory lifecycle to keep context fast, reusable knowledge clean, and historical storage compact.

## Memory Tiers

### 1. SHORT_TERM
**Purpose**: Fresh conversational context and high-churn memory writes.

- Default tier for new memory entries
- Session-adjacent context
- Fast-changing temporary values

### 2. KNOWLEDGE
**Purpose**: Stable, frequently reused, or explicitly pinned memory.

- Promoted from `SHORT_TERM` after reuse/pinning
- Stores high-signal facts, preferences, and decisions
- Serves as curated long-lived working knowledge

### 3. ARCHIVE
**Purpose**: Compressed/summarized historical memory artifacts.

- Receives summarized outputs from short-term and knowledge consolidation
- Used for broader historical context with lower noise
- Optimized for retention efficiency

## How Memory Works

### Conversation Flow
1. New memory is written to `SHORT_TERM`.
2. Retrieval prefers `SHORT_TERM`, then `KNOWLEDGE`, then `ARCHIVE`.
3. Reuse and policy signals can promote entries:
   - `SHORT_TERM -> KNOWLEDGE`
   - `SHORT_TERM -> ARCHIVE`
   - `KNOWLEDGE -> ARCHIVE`
4. Summarization/compression outputs are written to `ARCHIVE`.

### Memory Retrieval
Agents can retrieve memory by:
- tier-priority default ordering
- explicit tier filter (`SHORT_TERM`, `KNOWLEDGE`, `ARCHIVE`)
- namespace and key

## Lifecycle Cadence

To control storage growth and retrieval quality:

- **Monthly knowledge compaction**: stale `KNOWLEDGE` is consolidated toward `ARCHIVE`.
- **Bi-monthly archive cleanup**: archive scans for duplicate/similar artifacts and compaction candidates.

Cadence is configurable through environment variables.

## Memory Management

### Pruning Strategies
- **Tier-based**: stronger expiry in `SHORT_TERM`, curated retention in `KNOWLEDGE`
- **Compaction-based**: summarize and consolidate into `ARCHIVE`
- **Dedup-based**: merge similar archive artifacts over time

### Export and Backup
Export conversation memories:

```bash
# Via API
GET /api/memory/export?agentId=agent-123

# Via CLI
synapse-cli memory export --agent agent-123 --format json
```

## Privacy and Security

- User data isolated per tenant
- Encryption at rest (database)
- Encryption in transit (TLS)
- Configurable retention policies
- GDPR-compliant data deletion
