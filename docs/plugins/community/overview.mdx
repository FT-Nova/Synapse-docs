# Community Plugins

Explore plugins created by the SYNAPSE community.

## Overview

Community plugins are:
- 🌟 **Community-Driven**: Created and maintained by users
- 🧪 **Experimental**: May include cutting-edge features
- 🔓 **Open Source**: Publicly available on GitHub
- 🤝 **Collaborative**: Contributions welcome

## Installation

Install community plugins from the repository:

```bash
synapse plugin install --community plugin-name
```

Or install from a Git URL:

```bash
synapse plugin install --git https://github.com/username/my-plugin.git
```

## Quality & Safety

:::warning Community Plugins
Community plugins are not officially supported or audited. Review plugin code before installation.
:::

**Before installing:**
1. Check plugin ratings and reviews
2. Review source code on GitHub
3. Check for recent updates and active maintenance
4. Test in development environment first
