## Minimal requirements

| Area | Minimum |
|------|---------|
| CPU | 2 cores |
| RAM | 4 GB |
| Storage | 20 GB free |
| OS | Linux, Windows, or macOS |
| Docker path | Docker 24+ and Compose 2.20+ |
| Bare-metal path | Java 25, PostgreSQL 18, Redis 8, Qdrant 1.14, Node.js 24+, Maven 3.9+ |
