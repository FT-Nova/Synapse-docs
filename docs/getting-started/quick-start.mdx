# Quick Start

Get SYNAPSE running quickly with the installer scripts.

## Prerequisites

- Git
- Docker + Docker Compose installed and running

## Linux/macOS

```bash
git clone https://github.com/FTMahringer/Synapse.git
cd Synapse
chmod +x install.sh
./install.sh
```

## Windows (PowerShell)

```powershell
git clone https://github.com/FTMahringer/Synapse.git
cd Synapse
.\installer\install.ps1
```

## Verify

- Dashboard: `http://localhost:3000`
- Health: `http://localhost:8080/api/health`

Default credentials are `admin` / `admin` on first run. Change them immediately after login.

Need advanced setup (production hardening, bare-metal, Kubernetes, backup/monitoring)?
Go to [Full Installation Guides](../deployment/docker-compose.mdx).
